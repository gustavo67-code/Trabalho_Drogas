# 🚭 Trabalho Escolar: Drogas e seus Impactos

Projeto escolar desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de apresentar informações educativas sobre as drogas, seus tipos, efeitos no organismo e consequências para a saúde e a sociedade.

O projeto busca conscientizar os leitores sobre os riscos associados ao uso de drogas, destacando a importância da prevenção, da informação e da adoção de hábitos saudáveis.

### 🛠️ Tecnologias utilizadas
- **HTML5:** estruturação do conteúdo.
- **CSS3:** estilização e design da página.
- **JavaScript:** interatividade e funcionalidades do projeto.

### 🎯 Objetivos
- Informar sobre os diferentes tipos de drogas.
- Apresentar seus efeitos e possíveis consequências.
- Incentivar a conscientização e a prevenção.
- Aplicar conhecimentos de desenvolvimento web em um trabalho escolar.

### 📚 Finalidade
Projeto desenvolvido para fins educacionais, unindo tecnologia, pesquisa e conscientização social.
